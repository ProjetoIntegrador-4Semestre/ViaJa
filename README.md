# Viajá - Projeto Integrador

Aplicativo mobile de turismo desenvolvido para facilitar o planejamento de viagens. A plataforma permite explorar destinos, encontrar hospedagens e restaurantes, consultar informações sobre pontos turísticos e montar roteiros personalizados, reunindo diferentes etapas da viagem em um único aplicativo.


A referência atual de produto, planos, Stripe e revisão das telas está em [docs/product-baseline.md](docs/product-baseline.md). O [plano de recuperação](docs/recovery-plan.md) registra as verificações e o histórico técnico. Decisões planejadas não equivalem a funcionalidades implementadas.
